# Rust WASM AI Detection Module

This module contains AI browser detection logic compiled to WebAssembly using Rust and wasm-pack.

## Prerequisites

1. **Install Rust**: https://rustup.rs/
   ```bash
   curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
   ```

2. **Install wasm-pack**: https://rustwasm.github.io/wasm-pack/installer/
   ```bash
   curl https://rustwasm.github.io/wasm-pack/installer/init.sh -sSf | sh
   ```

3. **Verify installation**:
   ```bash
   cargo --version
   wasm-pack --version
   ```

## Building

### Quick Build

```bash
./build.sh
```

This script will:
- Check for `AI_DETECTION_SECRET` environment variable or `.secret` file
- Generate a secret if none exists
- Build the WASM module with the secret embedded
- Copy output files to `../public/wasm/`

### Manual Build

1. **Set the secret**:
   ```bash
   export AI_DETECTION_SECRET="AI_DETECT_SECRET_v1_$(openssl rand -hex 16)"
   ```

2. **Build**:
   ```bash
   AI_DETECTION_SECRET="$AI_DETECTION_SECRET" wasm-pack build --target web --release --out-dir pkg
   ```

3. **Copy to public**:
   ```bash
   mkdir -p ../public/wasm
   cp pkg/ai_detection_wasm_bg.wasm ../public/wasm/ai-detection.wasm
   cp pkg/ai_detection_wasm.js ../public/wasm/ai-detection.js
   cp pkg/ai_detection_wasm.d.ts ../public/wasm/ai-detection.d.ts
   ```

## Output Files

After building, you'll have:

- `pkg/ai_detection_wasm_bg.wasm` - The compiled WASM binary
- `pkg/ai_detection_wasm.js` - JavaScript bindings (auto-generated by wasm-pack)
- `pkg/ai_detection_wasm.d.ts` - TypeScript definitions
- `pkg/ai_detection_wasm_bg.wasm.d.ts` - WASM type definitions

These are copied to `../public/wasm/` with simplified names:
- `ai-detection.wasm`
- `ai-detection.js`
- `ai-detection.d.ts`

## Secret Management

The secret is embedded into the WASM binary at compile time. 

**Important**:
- Never commit the `.secret` file to git
- Use different secrets for dev/prod environments
- Keep WASM secret synchronized with server `AI_DETECTION_SECRET`
- Rotate secrets periodically

### Setting Secret for Production

1. Generate a strong secret:
   ```bash
   openssl rand -hex 32
   ```

2. Set as environment variable:
   ```bash
   export AI_DETECTION_SECRET="AI_DETECT_SECRET_v1_<your-secret>"
   ```

3. Build:
   ```bash
   ./build.sh
   ```

4. Set same secret on server:
   ```bash
   # In deployment config (Render, etc.)
   AI_DETECTION_SECRET="AI_DETECT_SECRET_v1_<same-secret>"
   ```

## JavaScript Integration

```javascript
// Load WASM module
import init, { 
    BrowserData, 
    DetectionResult, 
    detect_ai, 
    generate_proof 
} from '/public/wasm/ai-detection.js';

// Initialize WASM
await init('/public/wasm/ai-detection.wasm');

// Create browser data
const browserData = new BrowserData();
browserData.user_agent = navigator.userAgent;
browserData.platform = navigator.platform;
browserData.webdriver = navigator.webdriver || false;
// ... set other properties

// Run detection
const result = detect_ai(browserData);

// Generate proof
const sessionId = getSessionId();
const timestamp = Date.now();
const proof = generate_proof(sessionId, timestamp);

// Verify with server
const response = await fetch('/ai-detection/verify', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
        sessionId,
        proof,
        timestamp,
        detectionResults: {
            detected: result.detected(),
            reasons: Array.from(result.reasons()),
            severity: result.severity()
        }
    })
});

const verification = await response.json();
if (!verification.verified || verification.detected) {
    blockApplication();
}
```

## Development

### Testing Locally

```bash
# Watch mode (requires cargo-watch)
cargo install cargo-watch
cargo watch -x 'run'

# Run tests
wasm-pack test --headless --firefox
```

### Debug Build

```bash
wasm-pack build --target web --dev --out-dir pkg
```

### Optimize Further

The release build is already optimized, but you can:

```bash
# Install wasm-opt
npm install -g wasm-opt

# Further optimize
wasm-opt -Oz -o ai-detection.opt.wasm ai-detection.wasm
```

## Troubleshooting

### Build Fails: "cannot find `wasm_bindgen`"

```bash
# Install wasm-pack
curl https://rustwasm.github.io/wasm-pack/installer/init.sh -sSf | sh
```

### Build Fails: Missing dependencies

```bash
cargo update
```

### WASM won't load in browser

- Check browser console for errors
- Verify WASM file is served with correct MIME type (`application/wasm`)
- Check CORS headers allow WASM loading
- Ensure WASM file path is correct

### Verification fails

- Ensure WASM secret matches server `AI_DETECTION_SECRET`
- Check timestamp is recent (within 10 seconds)
- Verify session ID is valid
- Check server logs for error details
